এই বটটি রিয়েল-টাইমে নির্দিষ্ট টেলিগ্রাম গ্রুপ এবং চ্যানেলগুলির নতুন বার্তাগুলি বিশ্লেষণ করে এবং কিওয়ার্ড মিলে গেলে তাৎক্ষণিকভাবে বিজ্ঞপ্তি পাঠায়। এটি নতুন লক্ষ্যযুক্ত টেলিগ্রাম কমিউনিটি স্মার্টভাবে খুঁজে পেতে কৃত্রিম বুদ্ধিমত্তা (Groq, OpenRouter) ব্যবহার করে।

## ✨ মূল বৈশিষ্ট্যসমূহ

- 🚀 **রিয়েল-টাইম মনিটরিং:** কিওয়ার্ডযুক্ত বার্তাগুলি তাৎক্ষণিকভাবে আপনার নির্দিষ্ট গ্রুপে ফরওয়ার্ড করা হয়।
- 🤖 **দ্বি-স্তরের AI সার্চ:** লোকাল ডাটাবেস অনুসন্ধান এবং সমগ্র টেলিগ্রাম জুড়ে গ্লোবাল সার্চ।
- 📊 **XLSX এ এক্সপোর্ট:** ক্যাটাগরি এবং অ্যাক্টিভিটি ফিল্টারিং সহ এক্সেল ফাইলে সার্চ ও মনিটরিং ফলাফল ডাউনলোড।
- 🛡️ **অ্যাডমিন প্যানেল:** ডাটাবেস আপডেট, AI-এর মাধ্যমে বাল্ক ক্যাটাগরাইজেশন এবং চ্যাট ভাষা সনাক্তকরণের টুলস।
- 🌍 **বহুভাষিক সাপোর্ট:** রাশিয়ান, ইংরেজি, বাংলা সহ বহু ভাষার পূর্ণ সমর্থন (Fluent i18n)।
- 🔐 **মাল্টি-অ্যাকাউন্ট:** টেলিগ্রামের সীমাবদ্ধতা এড়াতে একাধিক `.session` ফাইল (StringSession) ব্যবহারের সুবিধা।
- 💰 **লিমিট এবং Telegram Stars:** প্রতি ২৪ ঘণ্টায় ১ বার বিনামূল্যে ডাটাবেস এক্সপোর্ট। অতিরিক্ত ডাউনলোড ৫ Telegram Stars-এর বিনিময়ে উপলব্ধ।

## 📝 প্রধান কার্যাবলী

- **মনিটরিং:** আনলিমিটেড গ্রুপ এবং চ্যানেলে নির্দিষ্ট কিওয়ার্ড ট্র্যাক করুন।
- **AI সার্চ:** ন্যাচারাল ল্যাঙ্গুয়েজ প্রম্পটের সাহায্যে নতুন টার্গেট গ্রুপ আবিষ্কার করুন।
- **স্মার্ট এক্সপোর্ট:** নির্দিষ্ট ক্যাটাগরি (ব্যবসা, ক্রিপ্টো, চাকরি ইত্যাদি) অনুসারে ডাটাবেস ডাউনলোড।
- **অ্যাক্টিভিটি যাচাই:** কমিউনিটিগুলিকে `active`, `inactive` অথবা `unknown` স্ট্যাটাসে চিহ্নিত করা।
- **বাল্ক সংযোজন:** `.txt` ফাইলের মাধ্যমে মনিটরিং চ্যানেল তালিকা আপলোড করুন।
- **প্রক্সি সাপোর্ট:** AI এবং টেলিগ্রাম API-এর নিরবচ্ছিন্ন সংযোগের জন্য HTTP/SOCKS5 প্রক্সি সমর্থন।

## ⚙️ দ্রুত শুরু (Quick Start)

1. **প্রয়োজনীয় প্যাকেজ ইনস্টল করুন:**
   ```bash
   python setup.py
   ```
   *স্ক্রিপ্টটি `requirements.txt` ইনস্টল করবে এবং `.env` ফাইল তৈরিতে সাহায্য করবে।*

2. **এনভায়রনমেন্ট কনফিগারেশন:**
   প্রজেক্টের রুট ডিরেক্টরিতে `.env` ফাইলটি পূরণ করুন:
   ```env
   BOT_TOKEN=...
   ID=... # my.telegram.org থেকে API_ID
   HASH=... # my.telegram.org থেকে API_HASH
   GROQ_API_KEY=...
   OPENROUTER_API_KEY=...
   ```

3. **রান করুন:**
   ```bash
   python main.py
   ```

## 👑 অ্যাডমিনিস্ট্রেটর ফিচার

অ্যাডমিন সুবিধাপ্রাপ্ত ব্যবহারকারীদের জন্য বিশেষ কন্ট্রোল প্যানেল রয়েছে:

- **🏷️ ক্যাটাগরাইজেশন:** LLM ব্যবহার করে স্বয়ংক্রিয়ভাবে গ্রুপগুলিকে ক্যাটাগরিতে বিভক্ত করা।
- **🌐 ভাষা ফিল্টার:** মানসম্মত আঞ্চলিক ডাটার জন্য চ্যাটের ভাষা নির্ণয়।
- **🔄 অ্যাকচুয়ালাইজেশন:** গ্রুপের মেটাডাটা বাল্ক আপডেট এবং কার্যকারিতা পরীক্ষা।

## 📊 অ্যাক্টিভিটি নির্ধারণ

| স্ট্যাটাস     | বিবরণ                                                        |
|:--------------|:-------------------------------------------------------------|
| 🟢 `active`   | সর্বশেষ বার্তাটি **≤ ৩০ দিন** আগে প্রকাশিত হয়েছিল            |
| 🔴 `inactive` | সর্বশেষ বার্তাটি **> ৩০ দিন** আগে প্রকাশিত হয়েছিল            |
| ⚪ `unknown`  | তারিখ পেতে ব্যর্থ (গোপনীয়তা বা অ্যাক্সেস সীমাবদ্ধতা)          |
