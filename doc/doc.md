# 📡 Документация по использованию бота AutoParseAlertBot

## 🚀 Основные функции

1. **Отслеживание ключевых слов** — мониторинг новых сообщений в указанных Telegram-группах и каналах в реальном
   времени.
2. **AI-поиск групп/каналов** — два режима поиска (локальный и глобальный) с использованием искусственного интеллекта
   (groq, OpenRouter, G4F).
3. **Актуализация базы данных** — автоматическое обновление информации о типах (группа/канал) и ID площадок
   администратором.
4. **Проверка групп** — ручная проверка конкретных чатов на наличие ключевых слов без подписки.
5. **Экспорт данных** — выгрузка базы в формат Excel (.xlsx) с фильтрацией по категориям и типам чатов.
6. **Многоязычная поддержка** — полный перевод интерфейса на русский и английский языки (Fluent i18n).
7. **Управление аккаунтами** — подключение нескольких аккаунтов через .session файлы для распределения нагрузки.
8. **Массовое добавление групп** — загрузка списков площадок через .txt файлы.
9. **Определение активности** — автоматический расчет статуса группы (active/inactive) по дате последнего сообщения.
10. **Интеллектуальная категоризация** — автоматическое присвоение тематических категорий группам с помощью AI.
11. **Определение языка** — автоматическое определение основного языка контента в группах.

## 🏢 Работа с закрытыми группами и мульти-аккаунтами (Тематические Кампании)

В версии 0.2.0 реализована полноценная поддержка многопоточного мониторинга разных тематических направлений (например, кампания **«Диваны»** и кампания **«Холодильники»**) и пересылки сообщений из **закрытых/приватных групп**.

### 1. Как работает отслеживание закрытых и приватных групп
Пользователь может самостоятельно «сажать» свои Telegram-аккаунты в любые закрытые чаты (например, авторизовавшись через Telegram Desktop / tdata на компьютере или смартфоне). После подключения сессии такого аккаунта к боту доступны следующие возможности:

1. **Режим «Все чаты аккаунта» (`track_all_chats`):**
   - Включается в 1 клик на карточке аккаунта в меню «🎯 Отслеживание» или в веб-интерфейсе.
   - В этом режиме аккаунт слушает сообщения во **всех открытых и закрытых группах и каналах**, в которых он состоит.
   - Пользователю не требуется вводить ссылки или ID закрытых чатов — бот пересылает любые совпадения по ключевым словам.

2. **Кнопка «📥 Импортировать чаты аккаунта»:**
   - Бот через Telethon сканирует список диалогов подключенного аккаунта и автоматически выгружает все доступные группы (включая приватные, в которые вступили через tdata) в базу данных отслеживания с сохранением их реальных `id_group` и названий.

3. **Добавление по приватной инвайт-ссылке:**
   - Поддерживаются ссылки форматов `https://t.me/+hash` и `https://t.me/joinchat/hash`. Бот использует метод MTProto `ImportChatInviteRequest` и вступает в чат.

4. **Добавление по числовому ID или точному названию:**
   - Если аккаунт уже состоит в закрытом чате, достаточно отправить боту числовой ID чата (например, `-1001234567890`) или точное название группы (например, `Мебельный Клуб Закрытый`). Бот автоматически найдет диалог среди чатов аккаунта.

### 2. Мульти-аккаунтность и независимые кампании (Пример заказчика)

Бот поддерживает параллельную работу нескольких аккаунтов одного пользователя с полной изоляцией задач:

- **Аккаунт №1 (Кампания «Диваны»):**
  - Подключенная сессия: Аккаунт 1 (`+79991112233`).
  - Собственная техническая группа: например, приватная группа *«Отслеживание: Диваны»*.
  - Собственные ключевые слова: *диван, софа, тахта, мягкая мебель, обивка*.
  - Собственные чаты: открытые и закрытые чаты мебельной тематики.

- **Аккаунт №2 (Кампания «Холодильники»):**
  - Подключенная сессия: Аккаунт 2 (`+79993334455`).
  - Собственная отдельная техническая группа: например, приватная группа *«Отслеживание: Холодильники»*.
  - Собственные ключевые слова: *холодильник, no frost, морозильная камера, компрессор*.
  - Собственные чаты: открытые и закрытые чаты бытовой техники.

#### Как запустить и управлять:
1. Откройте в боте меню **«🎯 Отслеживание»** -> **«👥 Мои кампании / Аккаунты»**.
2. Выберите нужный аккаунт:
   - Нажмите **«✏️ Сменить тему/название»** и задайте имя (например, `Диваны` или `Холодильники`).
   - Нажмите **«🔑 Ключевые слова темы»** и отправьте слова для этого направления.
   - Нажмите **«📥 Импортировать чаты аккаунта»** или включите **«🌐 Все чаты аккаунта: ВКЛ»**.
   - Нажмите **«▶️ Запустить этот аккаунт»** (или **«🚀 Запустить все аккаунты»** для одновременного старта).
3. При обнаружении сообщения бот отправит его строго в техническую группу соответствующей кампании с пометкой темы: `🏷️ [Диваны]` или `🏷️ [Холодильники]`.

## 🛠 Установка и настройка

### Быстрая установка

1. Запустите `setup.py` для автоматической установки зависимостей и первичной настройки:
   ```bash
   python setup.py
   ```

### Ручная установка

1. Установите необходимые библиотеки:
   ```bash
   pip install -r requirements.txt
   ```

2. Создайте файл `.env` в корневом каталоге проекта:
   ```env
   BOT_TOKEN=ваш_токен_бота
   ID=ваш_api_id
   HASH=ваш_api_hash
   GROQ_API_KEY=ваш_groq_api_key
   OPENROUTER_API_KEY=ваш_openrouter_api_key
   USER=прокси_пользователь
   PASSWORD=прокси_пароль
   IP=прокси_ip
   PORT=прокси_порт
   LANGUAGE=ru
   ```

3. Запустите бота:
   ```bash
   python main.py
   ```

## 💰 Лимиты на скачивание и Telegram Stars

Для снижения нагрузки на сервер на экспорт базы данных наложен лимит:

1. **Бесплатный экспорт** — доступен **1 раз в 24 часа** для любого типа экспорта базы.
2. **Платный экспорт** — повторные скачивания в течение 24 часов стоят **5 Telegram Stars**. При попытке скачать базу во
   время кулдауна бот предложит списать 5 звезд с вашего баланса или оплатить их напрямую.
3. **Пополнение звезд** — пополнить баланс можно в меню **"⚙️ Настройки"** -> **"💳 Пополнение звезд"** (доступны пакеты
   на 5, 15, 50 и 100 звезд).

## 🎯 Инструкция по использованию

### 1. Подключение аккаунта

Для работы (парсинга и поиска) боту нужны рабочие аккаунты:

1. Зайдите в **"⚙️ Настройки"** -> **"🔐 Подключить аккаунт"**.
2. Отправьте файл `.session` (Telethon).
3. Бот проверит валидность и добавит аккаунт в пул.

### 2. Настройка мониторинга

1. **Ключевые слова:** В настройках выберите **"🔍 Ввод ключевого слова"** и отправьте список слов/фраз (каждая с новой
   строки).
2. **Целевая группа:** Выберите **"📤 Подключить группу для сообщений"** и укажите `@username` группы, куда бот будет
   слать отчеты.
3. **Площадки:** Отправьте список `@usernames` или `.txt` файл со ссылками для мониторинга.

### 3. AI Поиск

Начиная с **версии 0.1.0 от 04 сентября 2026 года** AI поиск групп и каналов в Telegram с помощью подбора ключевых слов
доступен исключительно через Web-интерфейс (Telegram Web App) бота.

Для перехода к поиску откройте Web-панель и выберите вкладку **"AI поиск"** (`🤖`). В этом разделе доступны следующие
инструменты и режимы работы с указанием версий внедрения:

- **AI поиск групп / каналов (Одиночный поиск)** *(Базовый алгоритм с v0.0.5; перенос в Web UI с v0.1.0 от 04.09.2026)*:
    - **Назначение:** Быстрый поиск релевантных сообществ по 1 слову или словосочетанию (например:
      `Python Developer Jobs` или `Криптовалюты`).
    - **Принцип работы:** Использует AI (Groq Llama 3) для генерации вариантов поисковых запросов. Подключенный
      Telegram-аккаунт выполняет поиск совпадений в Telegram.
    - **Результат:** Найденая информация отображается в интерактивной таблице результатов (Название, Ссылка, Тип,
      Участники, Статус активности), сохраняется в БД и выгружается в Excel кнопкой **"Скачать результаты в Excel"** (с
      автоматической отправкой файла в ваш чат с ботом).

- **Массовый AI поиск групп / каналов** *(Добавлено в v0.1.0 от 04.09.2026)*:
    - **Назначение:** Масштабный перебор запросов через все подключенные аккаунты одновременно по нескольким ключевым
      словам или регионам (например: `Китай, Индия, Россия`).
    - **Принцип работы:** Бот автоматический разбивает ввод на отдельные ключевые слова. Сначала подбираются
      семантические вариации для Китая, затем для Индии, далее для России. Поиск распределяется по всем подключенным
      `.session` аккаунтам с защитой от лимитов.
    - **Результат:** Все найденные каналы и группы вносятся в базу данных, выводятся в итоговой таблице веб-панели и
      автоматически отправляются пользователю в виде файла Excel (`.xlsx`) прямо в Telegram.

- **База данных экспортных групп (Экспорт базы данных)** *(Выдача базы с v0.0.5 от 02.01.2026; разделение типов с
  v0.0.6; формат XLSX и категории с v0.0.9; Web UI и Telegram Stars с v0.1.0)*:
    - **Назначение:** Загрузка отфильтрованной таблицы Excel со всеми ранее обнаруженными и сохраненными в базе данных
      группами и каналами Telegram.
    - **Фильтрация по типам чатов** *(Добавлено в v0.0.6 от 11.01.2026)*:
        - *Вся база* — экспорт всех найденных площадок.
        - *Только каналы* — выгрузка только Telegram-каналов.
        - *Только группы* — выгрузка только супергрупп и чатов.
    - **Фильтрация по категориям и формат XLSX** *(Добавлено в v0.0.9 от 31.01.2026)*:
        - Выбор тематики из 20+ категорий (Инвестиции, Криптовалюты, IT, Бизнес, Недвижимость, Маркетинг и др.) или
          выгрузка всех категорий.
    - **Ограничения и платный экспорт (Telegram Stars)** *(Добавлено в v0.1.0 от 04.09.2026)*:
        - **Бесплатный экспорт:** доступен **1 раз в 24 часа**.
        - **Платный экспорт:** повторные скачивания во время 24-часового кулдауна стоят **5 Telegram Stars** (баланс
          звезд виден в шапке веб-панели, пополнить можно там же).

### 4. Панель администратора

Доступна по кнопке **"🛡️ Панель администратора"**:

- **🏷️ Присвоить категорию:** Обработка базы через groq или OpenRouter для распределения по темам.
- **🌐 Присвоить язык:** Определение языка (ru/en и др.) для каждой группы.

## 🟢 Статусы активности

| Статус          | Описание                                                 |
|:----------------|:---------------------------------------------------------|
| 🟢 **active**   | Сообщения были в течение последних 30 дней               |
| 🔴 **inactive** | Группа заброшена (более 30 дней тишины)                  |
| ⚪ **unknown**  | Не удалось получить данные (приватность или ограничения) |

## 📁 Структура проекта

- `account_manager/` — логика работы с Telegram API (Telethon).
- `ai/` — интеграции с LLM (groq, OpenRouter).
- `database/` — модели Peewee и работа с SQLite.
- `handlers/` — логика команд и диалогов aiogram.
- `locales/` — файлы локализации (.ftl).
- `keyboards/` — сборка кнопок интерфейса.

## Работа с ботом

1. Запустите бота.
2. В меню «Настройки» подключите аккаунт Telegram для отслеживания ключевых слов. Перейдите в настройки.
3. Выберите «Подключение аккаунта». В меню подключения аккаунта выберите подходящий для вас способ. Подключить аккаунт
   через сессию «Телефона». Подключить аккаунт через ввод номера телефона. Или подключить свободный аккаунт,
