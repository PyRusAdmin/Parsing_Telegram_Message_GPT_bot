يقوم البوت بتحليل الرسائل الجديدة في مجموعات وقنوات تليجرام المحددة في الوقت الفعلي، مع إرسال إشعارات فورية عند تطابق الكلمات المفتاحية. كما يستخدم تقنيات الذكاء الاصطناعي (Groq, OpenRouter) لاكتشاف مجتمعات تليجرام مستهدفة جديدة بذكاء.

## ✨ الميزات الرئيسية

- 🚀 **المراقبة في الوقت الفعلي:** إعادة توجيه فورية للرسائل التي تحتوي على كلمات مفتاحية إلى مجموعتك المخصصة.
- 🤖 **بحث ذكي ثنائي المستوى:** بحث محلي في قاعدة البيانات وبحث شامل عبر تليجرام بالكامل.
- 📊 **التصدير إلى XLSX:** تصدير نتائج البحث والمراقبة إلى Excel مع خيارات التصفية حسب الفئة ومستوى النشاط.
- 🛡️ **لوحة تحكم المشرف:** أدوات لتحديث قاعدة البيانات، وتصنيف المجموعات بالذكاء الاصطناعي، وتحديد لغات المحادثات.
- 🌍 **دعم متعدد اللغات:** دعم كامل للغة العربية والروسية والإنجليزية ولغات أخرى (Fluent i18n).
- 🔐 **حسابات متعددة:** دعم استخدام ملفات `.session` متعددة (StringSession) لتجاوز قيود تليجرام.
- 💰 **القيود و Telegram Stars:** تصدير مجاني لقاعدة البيانات (مرة واحدة كل 24 ساعة). التنزيلات الإضافية متاحة مقابل 5 من Telegram Stars.

## 📝 الوظائف الأساسية

- **المراقبة:** تتبع الكلمات المفتاحية في عدد غير محدود من القنوات والمجموعات.
- **البحث بالذكاء الاصطناعي:** العثور على مجموعات مستهدفة جديدة باستخدام استعلامات لغوية دلالية.
- **التصدير الذكي:** تنزيل بيانات القنوات حسب فئات معينة (أعمال، عملات رقمية، وظائف، إلخ).
- **تحديد النشاط:** تصنيف المجتمعات بالحالات `active` (نشط) أو `inactive` (غير نشط) أو `unknown` (غير معروف).
- **الإضافة الجماعية:** رفع قوائم المراقبة عبر ملفات `.txt`.
- **دعم البروكسي:** دعم بروكسي HTTP/SOCKS5 للاتصال المستقر بالذكاء الاصطناعي وواجهة تليجرام API.

## ⚙️ البدء السريع

1. **تثبيت الحزم البرمجية:**
   ```bash
   python setup.py
   ```
   *يقوم السكريبت بتثبيت `requirements.txt` والمساعدة في إعداد ملف `.env`.*

2. **تهيئة البيئة:**
   املأ ملف `.env` في المجلد الرئيسي للمشروع:
   ```env
   BOT_TOKEN=...
   ID=... # API_ID من my.telegram.org
   HASH=... # API_HASH من my.telegram.org
   GROQ_API_KEY=...
   OPENROUTER_API_KEY=...
   ```

3. **التشغيل:**
   ```bash
   python main.py
   ```

## 👑 ميزات المشرف

تتوفر لوحة تحكم مخصصة للمستخدمين الذين يمتلكون صلاحيات المشرف:

- **🏷️ التصنيف الآلي:** تصنيف المجموعات إلى موضوعات وفئات بواسطة نماذج اللغة الكبيرة (LLM).
- **🌐 تصفية اللغات:** تحديد لغة التواصل في المجموعات للحصول على عينات مستهدفة بدقة.
- **🔄 التحديث المستمر:** تحديث البيانات الوصفية للمجموعات بشكل مجمّع والتحقق من صلاحيتها.

## 📊 تحديد النشاط

| الحالة        | الوصف                                                         |
|:--------------|:--------------------------------------------------------------|
| 🟢 `active`   | تم نشر آخر رسالة قبل **≤ 30 يومًا**                           |
| 🔴 `inactive` | تم نشر آخر رسالة قبل **> 30 يومًا**                           |
| ⚪ `unknown`  | تعذر الحصول على التاريخ (قيود الخصوصية أو الوصول)             |
